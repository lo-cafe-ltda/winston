# Winston — installation and project links

Winston is a native Reddit client for iOS, written in Swift and SwiftUI. Its documented minimum requirement is iOS 17.

## Installation

The historical IPA packages are available in [Winston releases](https://github.com/lo-cafe-ltda/winston/releases). They can be installed with [Sideloadly](https://sideloadly.io/) or another compatible sideloading tool.
